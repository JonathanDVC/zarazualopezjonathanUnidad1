# Proyecto Unidad 1

Sitio web desarrollado con:

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Validación Frontend
- Validación Backend
- Validación humana
- Buzón de contacto
- Recuperación de contraseña
- Mapa del sitio
- Página de error

## Base de Datos

Importar el archivo SQL proporcionado.

## Ejecución

1. Copiar la carpeta a htdocs.
2. Iniciar Apache y MySQL en XAMPP.
3. Crear la base de datos unidad1.
4. Importar las tablas.
5. Abrir:
